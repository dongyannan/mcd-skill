## 1. 06:20 北京南站 —— 早餐「来不来得及」

先看动态忌口怎么结算（北京 10 月，12℃）：

```bash
mcd-biztravel prefs --city 北京 --temp 12 --hour 8 --meal breakfast
```

```text
动态忌口结算
──────────────────────────────────────────────
场景：北京 · 10 月 · 8:00 · 餐次 早餐
  气温 12℃（来自 --temp 实传）· 华北
  冰量 → 去冰（优先热饮）
  硬禁忌 → 香菜、花生

推导过程：
  - 档案偏好：常温（L2，可被动态层覆盖）
  - 动态层（气温）：气温 12℃ < 15℃ → 去冰
  - ⚠️ 动态层覆盖静态偏好：常温 → 去冰
  - 动态层（时段）：早餐时段 → 优先热饮
```

配早餐（额度 ¥20）：

```bash
mcd-biztravel plan --city 北京 --meal breakfast --budget 20 --temp 12 --hour 8
```

```text

──────────────────────────────────────────────────────────

```

## 2. 15:00 深圳（对比）—— 同一份档案，两个答案

```bash
mcd-biztravel prefs --city 深圳 --temp 32 --hour 15 --meal afternoon
```

```text
  气温 32℃（来自 --temp 实传）· 华南
  冰量 → 加冰
  - ⚠️ 动态层覆盖静态偏好：常温 → 加冰
```

> **这就是「动态忌口」**：不是两条配置，而是**同一条规则在两个城市求值出的两个结果**。

同样 4 个人，换成上海 19℃：

```bash
mcd-biztravel hospital --city 上海 --people 4 --temp 19 --price
# → 场景气温 19℃ → <22℃ → 全热饮
```

## 5. 想自己试工具？

```bash
mcd-biztravel doctor                          # 连通性 + 工具清单
mcd-biztravel mcp --tool query-my-account     # 直通调用，默认只读
```

写操作（如 `create-order`）**不加 `--yes` 一定被拦截**：

```bash
mcd-biztravel mcp --tool create-order --args '{"storeCode":"1950040"}'
# → 打印「将要发生什么」后拦截，不会真实下单
```
